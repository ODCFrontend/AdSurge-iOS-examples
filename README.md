# AdSurge iOS Examples

Sample apps for the AdSurge iOS SDK, in Objective-C (`AdSurgeDemo/`) and Swift
(`AdSurgeDemo-Swift/`).

## Setup

Pick a demo, install pods, and open the generated workspace:

```bash
cd AdSurgeDemo        # or AdSurgeDemo-Swift
pod install
open AdSurge.xcworkspace
```

Then Build & Run (⌘R) in Xcode.
